# SkyWings Game

A Flappy Bird-inspired game built with TypeScript and HTML5 Canvas.

## Features

- Animated bird
- Moving pipes
- Collision detection
- Score system
- Best score tracking
- Countdown start
- Sound effects
- Scrolling clouds
- Scrolling ground

## Controls

SPACE = Jump

- TypeScript
- HTML5 Canvas
- CSS
